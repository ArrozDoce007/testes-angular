# 🚀 Projeto Questão 04

## 📌 Sobre o Projeto

Projeto desenvolvido utilizando Angular com suporte a testes unitários utilizando Vitest.

---

# 📦 Instalação Local

## 1️⃣ Baixe o Projeto

Baixe o arquivo `.zip` do projeto e extraia em uma pasta de sua preferência.

---

## 2️⃣ Acesse a Pasta do Projeto

Abra a pasta `questao_04` no seu ambiente de desenvolvimento  
(VS Code, WebStorm, etc.) ou execute no terminal:

```bash
cd questao_04
```

---

## 3️⃣ Instale as Dependências

Execute o comando abaixo para instalar todas as dependências do projeto:

```bash
npm install
```

---

# ▶️ Executando o Projeto

Após instalar as dependências, execute:

```bash
ng serve --open
```

O projeto será aberto automaticamente no navegador.

---

# 📊 Cobertura de Testes

Para executar os testes com relatório de cobertura:

```bash
npx vitest run --coverage
```

---

## 📁 Relatório de Cobertura

O relatório será gerado na pasta:

```bash
coverage/
```

Para visualizar o relatório completo no navegador, abra:

```bash
coverage/index.html
```

---
